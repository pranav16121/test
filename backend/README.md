# College Lost and Found Backend API

A fast, production-ready Python backend for the College Lost and Found prototype. This project exposes REST API endpoints for lost/found item submission, search/filtering, and status updates, powered by **FastAPI**, **Supabase (PostgreSQL)**, and **Cloudinary** for image uploads.

---

## Project Structure

This project follows your specified layout:
```
lost-and-found/
├── backend/
│   ├── main.py          # FastAPI web server and routing
│   ├── items.py         # DB operations for lost_found_items table
│   └── supabase_client.py # Initializes the Supabase client connection
├── .env                 # API keys & DB configurations (Supabase, Cloudinary)
├── requirements.txt     # Python package requirements
└── README.md            # Installation & usage instructions
```

## 1. Database Setup (Supabase)

To host your database in the cloud:

1. Create a free account or sign in at [Supabase](https://supabase.com).
2. Create a **New Project** (set a database password and save it!).
3. Once provisioned, click on **SQL Editor** in the left sidebar.
4. Click **New Query** and run the following SQL code to create the `lost_found_items` table:

```sql
CREATE TABLE lost_found_items (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  type TEXT NOT NULL CHECK (type IN ('lost', 'found')),
  title TEXT NOT NULL,
  description TEXT,
  category TEXT NOT NULL,
  location TEXT NOT NULL,
  date DATE NOT NULL,
  status TEXT DEFAULT 'active' CHECK (status IN ('active', 'resolved')),
  image TEXT,
  contact_email TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT now()
);
```

5. Go to **Project Settings** (gear icon) -> **API** in the sidebar.
6. Copy your **Project URL** and the **anon (public)** key.
7. Paste these values into your `.env` file (see below).

## 2. Cloud Image Storage Setup (Cloudinary)

To store uploaded item photos in the cloud:

1. Sign up for a free account at [Cloudinary](https://cloudinary.com).
2. In your Cloudinary Console dashboard, copy your **Product Environment Credentials**:
   - **Cloud Name**
   - **API Key**
   - **API Secret**
3. Paste these values into your `.env` file (see below).

## 3. Installation & Run Instructions

### A. Install Dependencies
Make sure you have python installed. In your terminal, run:
```bash
pip install -r requirements.txt
```

### B. Setup Environment Variables
Create a `.env` file in the root of the project (copying `.env.example` as a template) and add your keys:
```env
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_KEY=your-anon-public-key

CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```
*Note: If Cloudinary keys are not provided, image uploads will fallback to saving locally in `static/uploads/`.*

### C. Run the Backend API
Start the FastAPI server using Uvicorn:
```bash
uvicorn backend.main:app --reload
```
The server will start at `http://127.0.0.1:8000`.

### D. Explore Interactive API Docs
Open your browser and navigate to:
**`http://127.0.0.1:8000/docs`**

FastAPI automatically generates interactive Swagger documentation, allowing you to test item creation, filters, search queries, status updates, and image uploads directly from the browser UI.

## 4. Running Unit Tests

To run the automated mock integration tests (which verify the endpoints without requiring active database connections):
```bash
python test_backend.py
```
This runs the test suite and verifies all FastAPI route integrations.
